Тестовое задание для одной из компаний

Срок выполнения: 72 часа

Не использовать ECS, использовать MVP, Zenject, Pool. использовать очередь запросов для получения данных с сервера. 

Первая вкладка: простой игра-кликер

Вторая вкладка: список погоды (грузит с сервера)

Третья вкладка: список собак (грузит с сервера). 
При нажатии на вкладку - отображается информация о породе (подгружает с сервера). Окно с текстом о породе подстраивается под объем текста

Все ассеты, эффекты, звуки и музыку необходимо было подобрать самостоятельно.
